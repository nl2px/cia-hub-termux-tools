# Base de données locale

Ce dossier est réservé aux données locales utilisées avec l’outil.

Ne publiez jamais ici de mots de passe, tokens, adresses e-mail, numéros de téléphone ou données provenant d’une fuite. Les fichiers de données restent ignorés par Git ; seuls ce document et la structure du dossier sont publiables.

Pour tester la recherche localement, utilisez uniquement des données fictives et anonymisées dans un fichier `.txt` non suivi par Git.
